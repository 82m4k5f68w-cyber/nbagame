# Third-party and generated assets

Every file under `assets/` (and everything the pipelines in `scripts/assets/` inline into a build) comes from a
free-for-any-use source (CC0 / public domain / permissive) or is generated by this project. Re-run the pipelines
instead of editing outputs by hand.
